## The entry

One short line about office life, written by `main.ts` to `/output/entry.txt`:

> The meeting could have been an email, the email could have been a Slack message, and the Slack message could have been silence.

## How it works

`main.ts` (pure Node.js standard library, no dependencies, no network) writes the
127-character joke to `/output/entry.txt` and self-checks it against the
competition gate: 1 to 200 characters, not only whitespace.

Run it locally:

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
